# ACE 开发助手 · 产品与供应链开发（本地版）

面向产品与供应链开发专员的轻量级桌面工具。数据与账号全部保存在本机，离线可用。

## 快速开始

直接双击 `dist/SupplyDevLocal-vX.Y.Z.exe` 启动（文件名带版本号，每次打包自动递增，`dist/` 保留历史版本）。首次启动需创建本地账号（用户名+密码，仅保存在本机）。

## 功能

- 仪表盘：项目甘特图（**可垂直滚动、高度铺满**，时间范围筛选/品类分组/里程碑菱形四态标记/周网格线/交付里程碑圆点与依赖连线/进度百分比，**点击项目行或里程碑菱形可下钻详情**；**依赖连线编辑：点「✎ 编辑依赖」进入模式，先点前置再点后继选择类型（FS/SS/FF/SF），自环/重复/成环自动拦截，点击连线查看/删除；关键路径（DAG 最长链）橙色高亮描边，逾期关键节点进入风险提醒**）、待办提醒、**关键日期看板（月历网格，点击日期查看当天待办与日期节点，节点标记完成状态，条目可跳转详情/模块）**、风险提醒（定价倒挂/无BOM/逾期/待排款/关键路径逾期/ETA 严重滞后）、近期到期节点（**未来30天**）；**待办提醒/风险提醒/近期到期节点三张卡片支持「收起/展开」折叠**；**数据速览：项目状态分布（平均进度+各状态堆叠条+各状态项目明细点击直达详情）、供应商风险 TOP（综合评分<80）、近6月新增项目柱图、毛利健康度（平均定价毛利+亏损/微利 TOP）、最近动态（操作审计）**
- 项目详情页：中文标签页（概览/打样/成本/供应商/订单/质量），各模块内均有「+ 新增」入口（打样/报价/BOM/订单/客诉/里程碑），概览含基本信息（**可编辑，含负责人**）、里程碑时间轴（可增删改+CSV 导入导出）、逾期告警 banner（里程碑/订单逾期醒目提示，含严重逾期天数）
- 品类自定义：新建/编辑项目时点击「+ 自定义品类」即可输入并添加新品类，持久化保存、自动去重，后续所有品类下拉均可选
- 逾期语义：三级预警（剩余 >3 天灰、剩余 ≤3 天橙、逾期红、逾期 >7 天深红严重逾期），一律显示「剩 N 天 / 逾期 N 天」，区分主动改期（延期）与被动超期（逾期）
- 顶栏：今天日期+星期+时间（联网多源同步：淘宝时间源/worldtimeapi/timeapi.io 三源采样取中位数，离群源自动丢弃，偏移持久化离线复用，每 30 分钟周期校准；**每次成功同步记录漂移历史（最近 30 条），偏移超过 5 秒自动告警提示校准系统时钟**；同步状态标识 ⟳ 同步中 / ✓ 已同步 / ⚠ 未联网，离线回退本地时钟）；**全局搜索框（输入即搜：项目/供应商/订单/客诉/物料/里程碑 6 类数据实时候选浮层，命中高亮、无匹配空态提示、点击结果直达详情/模块，Enter 跳转第一条，Esc/失焦关闭）**
- **全局快捷键**：`Ctrl+K` 聚焦全局搜索、`Alt+1~8` 切换八大板块、`Ctrl+S` 立即保存到本地、`Esc` 关闭搜索浮层/弹窗

## 数据导入导出

- 右上角「导出/导入」：JSON 全量备份与恢复（含格式校验与缺集合兜底；**可选密码加密，导入自动识别**）
- 各模块 CSV 导出：项目/供应商/订单/物料/工艺/BOM/打样/客诉/报价/抽检/整改/里程碑/任务依赖/品类权重/资质证书（15 模块，表头含 ID 与业务字段，可直接回导；依赖按「产品ID+里程碑名」定位，权重表可直接回导并联动评级）
- CSV 批量导入：与导出同 15 模块（表头与导出格式一致）；逐行校验必填/类型/引用完整性（产品/供应商/物料/订单 ID 存在性、依赖自环/成环/重复拦截）、错误行不入库并弹窗前 10 条+运行日志全量清单、按 ID/业务唯一键去重跳过、导入后自动联动（项目状态/供应商评分/成本快照/打样确认日期/权重变更重算评级）

## 数据安全

- **启动自动备份**：每次启动应用自动把业务状态备份到 `~/.supplydev/backups/`（JSON，滚动保留最近 7 份）。如备份未生效，查看 `~/.supplydev/backup_debug.log` 可定位失败环节。
- **备份完整性校验**：自动备份还带 SHA-256 清单（`~/.supplydev/backups/index.json`），应用启动后会自动校验最近一份是否被损坏或截断；异常时写入运行日志并提示手动导出一次备份。
- **7 天未备份提醒**：自动备份成功会记录时间戳；超过 7 天没有成功备份，启动时会弹提示建议手动导出一次。
- **备份可选密码加密（AES-GCM）**：右上角「导出」时可选填密码——填了则产出 AES-GCM-256 加密备份（PBKDF2-SHA256 十万迭代派生密钥，随机盐+随机 IV）；导入时自动识别加密文件并弹密码框。**忘密码不可恢复**，请妥善保管。不填密码则和以前一样导出明文 JSON。
- **双开防护**：同一 Windows 登录会话内仅允许运行一个实例，重复启动会弹窗提示并退出（防止两个实例互相覆盖数据）。
- **CSV 公式注入防护**：导出的 CSV 中以 `=` `+` `@` 开头的文本自动加前导空格（Excel/WPS 打开不会被当公式执行）；重新导入时自动还原，往返无损。
- **密码加盐存储**：本地账号密码使用 PBKDF2-SHA256（10 万迭代 + 随机盐），旧账号在下次登录时自动透明升级，无需重置。

## 技术栈

- 前端：单文件 `supplydev.html`（原生 JS + CSS，无构建）
- 壳：pywebview（Windows 桌面，应用图标为品牌蓝渐变白徽章对勾，由 `assets/make_icon.py` 生成多尺寸 ICO）
- 数据：IndexedDB（权威源 `supplydev_db`）+ localStorage 镜像，存于 `~/.supplydev/`（pywebview `storage_path`，须 `private_mode=False`）
- 打包：PyInstaller

## 重新打包

```
python build.py
```

版本号自动 patch +1（读 `version.txt`），产物输出到 `dist/SupplyDevLocal-vX.Y.Z.exe`（文件名带版本号）。

注意：每次打包会先清空 `build/` 和旧 spec 文件；`dist/` 中的历史版本 exe 一律保留，不删除。

## 数据位置

业务数据和本地账号保存在 `%USERPROFILE%\.supplydev\`，卸载 exe 不影响数据。
