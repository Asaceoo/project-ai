# v1.0.43 发布清单（C11 联动与实时性批次）

## 变更明细（修改前/后）

| # | 修改前 | 修改后 |
|---|---|---|
| 1 | **死数据 P0**：项目 progress 只在手工编辑/订单完成时写入，改里程碑状态后项目卡片/仪表盘平均进度/详情页进度全不动 | 新增 `recalcProgress(pid)`：进度=里程碑完成比例自动重算，挂接里程碑增/删/改三个保存点 |
| 2 | **联动断点**：报价采纳/拒绝后供应商评分不重算 | `quoteStatus` 加 `recalcSupplierScore` |
| 3 | **联动断点**：报价改价后评分与成本快照不联动 | `editQuote` 改价后 `snapshotCost` + `recalcSupplierScore` |
| 4 | **逾期覆盖缺口**：详情页打样表截止列只有日期无倒计时 | 新增「倒计时」列，overdueState 四级配色（剩N天/临期/逾期N天/严重逾期） |
| 5 | **逾期覆盖缺口**：报价有效期过期无提示 | 有效期列过期红字「已过期 N 天」、临期橙字「剩 N 天」 |
| 6 | **实时性**：时钟同步偏移校正后页面数据不重算 | `syncTime` 偏移变化>60s 时全量 RENDER |
| 7 | **编辑模式缺口**：BOM 组成项只有删除 | 新增 `editBOM`：编辑物料/工艺/用量/损耗/半成品引用（含循环引用拦截），详情成本 tab 与成本页 BOM 报价两处入口 |
| 8 | **编辑模式缺口**：物料只有调价入口 | 新增 `editMaterial`：编辑名称/品类/规格/单位/供应商/状态 |
