# SupplyDevLocal v1.0.46 发布清单（C14 数据安全补强批次）

## 变更内容

1. **运行中周期自动备份**：`startPeriodicBackup()` 每 5 分钟巡检，满足「距上次成功备份 ≥24h 且备份后有数据变更」才落盘；无变更不写盘、导入中（`_impPrev`）不备份中间态
2. **备份发送统一入口**：新增 `bkSendState(cb)`，启动备份 `tryBk` 与周期备份共用（消除两处 fetch 口径漂移，verify 加「POST 入口唯一」断言）
3. **备份完整性校验**：app.py 落盘写 `backups/index.json`（字节数 + SHA-256）；新增 GET `/verify?token=` + `Api.verify_backup()`；前端启动 15s 后自动校验，ok / corrupt / missing / no-backup 四态区分（no-backup 静默）
4. **备份文件名防撞**：`%Y%m%d-%H%M%S` → 追加微秒，同秒两次备份不再互相覆盖
5. **审计留痕不丢失**：`_audit` 满 300 条溢出转 `_auditArc` 归档（上限 2000 条）；新增「查看归档」弹窗与「导出全量」CSV；团队页日志卡片接入两个入口
6. **全局搜索扩容**：6 类 → 12 类实体（新增报价/证书/整改/抽检/工艺/成员），命中上限 15 → 20，`goSearchHit` 补落点映射

## 已知限制

- 审计归档上限 2000 条（超出仍会丢最旧）——长期留痕请用「导出全量」CSV 落盘保存
- 周期备份依赖本地 HTTP 通道（bkport.js）；浏览器直开或通道未就绪时静默跳过，仅启动备份重试 5 次
- `verify_backup` 校验的是**最近一份**备份，历史备份若被外力损坏不会主动扫描发现

## 待真机确认

4. 顶栏搜索输入供应商名/产品名，应能命中「证书」「报价」「抽检」等新类型并点击直达对应板块
