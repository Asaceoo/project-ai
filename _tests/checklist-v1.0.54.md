# 发布清单 v1.0.54（C23：日志体系成熟化）

## 功能

- **内核**：日志自增序号（断点续号）、启动会话标识（id+启动时间+版本）、环形缓冲 1000/800
- **性能观测**：慢渲染 >300ms warn、慢落盘 >500ms warn
- **一键诊断包**：日志+审计尾+环境元数据（UA/屏幕/时区/存储占用/IndexedDB 状态/备份通道端口）单 JSON 导出，不含业务数据与凭据
- **打点补全**：登录、CSV 导出（审计双通道）；备份通道失败分级（HTTP warn/异常 error/未配置 debug）；评分重算、路由切换（debug）
- **查看器**：级别计数徽章、行首序号、标题含会话 id 与版本

## 已知限制

- session.ver 为启动时快照；窗口标题被外部改写时 getAppVer 兜底 'dev'
- 诊断包 logs 为环形缓冲全量（≤1000 条），更早日志已被覆盖（设计如此）
- debug 级日志不落盘（仅 warn/error 立即落盘 + 批量落盘点），极端崩溃前最后几条 debug 可能缺失
