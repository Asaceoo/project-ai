# 发布清单 v1.0.56（C25：项目详情甘特图）

## 本版功能

- **项目详情新增「甘特」tab**（概览之后）：对标参考图形态——
  - 左侧 WBS 任务树表格（编码 1 / 1.1 / 1.2 + 任务名 + 状态标签），横向滚动时左列吸附；
  - 右侧时间区：月+日两级表头（纵向吸附）、今日红线、周末浅色条纹（repeating-linear-gradient 单层实现）、分组汇总条（深色实条，min~max 跨度 + n/m 完成）、里程碑工期条（endDate 存在时，颜色取里程碑色字段）+ 条尾任务名、菱形节点（无 endDate）；
  - 时间范围自适应（里程碑/分组跨度 ∪ 项目 ideaDate/targetDate，最小 14 天）；
  - 点击里程碑条/菱形 → msDrill 下钻；分组条不可点（防 NaN）；
  - 空项目显示引导文案。
- 明确不做（另行排期）：拖拽调日期、复选框/序号列、撤销重做、缩放工具栏、依赖连线。
