# 发布清单 v1.0.58（C27 甘特任务层 + 项目总时长标注）

## 一、功能变更

| # | 变更 | 说明 |
|---|---|---|
| 1 | **项目总条** | 甘特顶部新增项目汇总行：左列项目名，右区蓝色总条覆盖内容跨度（里程碑/任务/分组 ∪ ideaDate/targetDate），标注「总时长 N 天」（含首尾）；跨度不完整（单端真值）或全空不渲染 |
| 2 | **任务实体（kind='task'）** | 弹窗类型三选：任务（工期条）/里程碑（节点）/阶段分组；任务必填开始+结束日期；与里程碑同权参与进度/依赖/时间轴/聚合（排除语义零迁移） |
| 3 | 任务行标识 | 甘特左列任务行加灰色「任务」tag |
| 4 | CSV | 类型列支持「任务/task」→ kind='task'，校验与弹窗一致（三处校验站点） |
| 5 | 文案 | 甘特 tab 按钮「+ 任务 / 里程碑」；弹窗标题/label 同步；合并 C26 遗留的重复日期校验行 |
