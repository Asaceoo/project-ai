# C22 需求文档：甘特图两级 WBS 树 + 里程碑工期条

> 参考对标：进度猫（jindumao.com）甘特图截图 ｜ 版本：v1.0.53（拟） ｜ 日期：2026-10-01

## 1. 背景与目标

用户对标进度猫截图提出：甘特图需要「左侧任务树（编码/WBS/任务名多级缩进）+ 右侧时间条（分组汇总条 + 任务工期条）」。此前调研（MS Project 系/进度猫）定案走 **A+B 档**：两级树 + 工期条，覆盖截图 90% 观感；关键路径/依赖顺延（C 档）已有依赖连线基础，本轮不做自动顺延。

## 2. 功能需求

### 2.1 数据模型（milestone 实体扩展，向后兼容）

| 新字段 | 类型 | 说明 |
|---|---|---|
| `kind` | `''` \| `'group'` | `'group'`=阶段分组节点：不参与进度计算/依赖连线/基线快照，仅收纳子项 |
| `parentId` | string | 所属分组 id；`''`/缺失=顶层。仅支持一级（分组不可再嵌套） |
| `endDate` | `YYYY-MM-DD` | 工期条结束日期；有且晚于 date 时画条，否则维持菱形 |

- 旧数据无新字段 → 全部按顶层里程碑处理，零迁移。
- WBS 编码为**展示层计算**（顶层 1,2,3…；分组子项 n.k），不落库。

### 2.2 甘特图（项目汇总页）

1. 项目行左侧加**展开箭头**（▸/▾），展开后按录入顺序渲染两级树：阶段分组行 → 里程碑行。
2. 左列（200px）：WBS 编码（等宽字体灰字）+ 缩进（分组 1 级、子项 2 级）+ 名称；分组行带折叠箭头与「完成 n/m」。
3. 右侧时间轴：
   - **分组汇总条**：深色描边 + 绿色浅底，跨度 = 子项 min(date) ~ max(endDate‖date)；无子项不画。
   - **里程碑工期条**：date→endDate 实色圆角条（颜色沿用 msState 四态），条尾标注任务名。
   - **菱形**：无 endDate 的里程碑维持现状（四态着色）。
   - 依赖连线 marks 取自实际渲染行位（展开后取子行 y，收起取项目行 y），SVG 连线不错位。
4. 折叠/展开为会话内 UI 状态（`ganttExpand`/`wbsFold`），不落库。

### 2.3 里程碑新增/编辑弹窗

- 新增「类型」：里程碑 / 阶段分组（分组日期可不填、状态忽略）。
- 新增「归属阶段」下拉（选项随所选项目联动，仅列该项目分组）；编辑时可改归属。
- 新增「结束日期」（选填）：必须晚于开始日期，否则拦截报错。
- 分组→里程碑转换要求补日期；里程碑→分组仅当无子项。

### 2.4 联动与红线

- `recalcProgress`/`msSummary` **排除分组节点**（进度=非分组里程碑完成比例，防派生数据污染）。
- `msSyncDates`/`msRefillBaseline`/`snapBaseline` 跳过分组节点。
- `addDep` 拦截分组节点参与依赖（提示，不入 state.deps）。
- `delMilestone` 删分组时**子项上移顶层**（不级联删，防数据丢失），审计打点注明。
- CSV 导入（milestones）新增可选列：`类型`/`父阶段`/`结束日期`；缺列按旧格式兼容（顶层里程碑）。导出同步补列。
- 按钮语法红线：新 inline onclick 闭合形态 `fn(\'id\')"`，过 verify 全路由 onclick 语法审计 + deadbtn。

## 3. 非功能需求

- 单文件红线：全部改动在 supplydev.html（原生 JS，无新依赖）。
- 颜色红线：新增色值仅限既有语义变量或 msState 四态色。
- 渲染错误边界：ganttHTML 在 RENDER 边界内，展开/折叠走 `RENDER()`（scheduleRender 不引入新定时器）。

## 4. 验收标准

1. 旧行为回归：不展开时甘特图与 v1.0.52 视觉一致（分组节点不出现菱形）。
2. 展开：两级树 + 编码 + 汇总条 + 工期条 + 菱形混排正确，依赖连线不错位。
3. 分组不计进度：仅子里程碑参与完成比例；删分组子项上移。
4. CSV 新旧格式均可导入。
5. verify.js C22 批次（源码 + 行为级）全绿，deadbtn 0。
