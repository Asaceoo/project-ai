# REQ-C25：项目详情甘特图（对标参考图甘特形态）

## 背景与目标

用户给出参考图（专业甘特编辑器：左侧 WBS 任务树表格 + 右侧时间条形区），要求将该形态做进**项目详情**：新增「甘特」tab，展示**单项目**的 WBS 任务树与时间条。

## 需求范围

### P0（本版）

1. 项目详情新增「甘特」tab（排在「概览」之后），复用现有 detailTab 切换机制。
2. 左侧任务树表格：WBS 编码（顶层 n / 分组子项 n.k，复用 `msWbsCodes`）+ 任务名称，分组行加粗缩进、子行二级缩进；左列**横向滚动时吸附**（position:sticky）。
3. 右侧时间区：
   - 月 + 日两级表头（表头纵向吸附）；
   - 今日竖线（红）；
   - 周末浅色条纹（repeating-linear-gradient 单层实现，防 DOM 膨胀）；
   - **分组汇总条**（深色实条，min~max 跨度，条内「名称 · n/m 完成」，复用 `msGroupSpan`）；
   - **里程碑工期条**（endDate 存在时画实色条，颜色取里程碑自身 color 字段）+ 条尾任务名；
   - **菱形节点**（无 endDate 的里程碑，四态语义沿用颜色字段）。
4. 时间范围自适应：里程碑/分组跨度 ∪ 项目 ideaDate/targetDate，前后各留 3/7 天，最小 14 天。
5. 空状态：无任何里程碑/分组时显示引导文案。
6. 点击里程碑条/菱形 → `msDrill` 下钻（分组条不可点，防 msState 对无日期分组出 NaN）。

### 明确不做（本期）

- 拖拽调日期、复选框、序号列、撤销/重做、缩放工具栏（参考图的编辑器外壳能力，另行排期）。
- 依赖连线（项目详情 v1 从简；仪表盘甘特已有关键路径）。

## 红线与约束

- 单文件 / 原生 JS；新增颜色一律 `var(--xxx)`（业务状态色对象 hex 豁免，沿用 C7 口径）。
- 分组不变量沿用 C22：分组不参与进度/依赖/基线/逾期聚合；本项目甘特中分组仅作汇总行。
- inline onclick 闭合形态 `fn(\''+id+'\')`，过 verify 全路由语法审计。
- 时间计算走 parseDate/addDays/todayStr（含 TIME_OFFSET 校准），禁裸 new Date。

## 验收标准

- verify.js 新增 C25 批次：源码级（tab 注册/吸附布局/汇总条/今日线）+ 行为级（切 tab 渲染出 WBS 编码与分组汇总条、空状态、分组行不可点）。
- 全量 verify 0 FAIL、deadbtn 0，打包后 exe 冒烟 + 真机截图确认。
