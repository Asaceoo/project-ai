# REQ-C27 甘特图任务层与项目总时长标注（v1.0.58）

## 背景

用户真机验收 C25/C26 后提出：①总项目时长要标出来（标出长度）；②不单只有里程碑，还要有任务——一个项目下有多个任务。

## 现状与兼容性结论

当前数据模型（C22）：项目 → 阶段分组（kind='group'，不参与进度）→ 里程碑（kind=''，节点/工期条）。
全站聚合均为**排除语义** `kind!=='group'`（进度 recalcProgress/依赖 CSV 解析/时间轴/打印/自检 11 处）——新增 `kind:'task'` 自动继承全部行为，**零迁移、零聚合改动**。

## 需求

### R1 项目总条（总时长标注）
- 甘特图顶部新增「项目汇总行」：左列项目名，右区深蓝总条覆盖**内容跨度**（里程碑/任务/分组的 min(date) ~ max(endDate||date)，∪ ideaDate/targetDate）。
- 总条标注「总时长 N 天」（含首尾），悬浮提示明细区间；**不含甘特前后 padding（-3/+7）**。
- 项目无任何日期时不渲染该行。

### R2 任务实体（kind='task'）
- 弹窗类型三选：**任务（工期条）/ 里程碑（节点）/ 阶段分组（不参与进度）**，新增+编辑双站点。
- 任务**必填**开始+结束日期（工期条长度）；里程碑必填开始日期、结束日期选填；分组可空。
- 任务参与进度/依赖/基线/时间轴/逾期聚合（与里程碑同权，排除语义自动兼容）。
- 甘特左列任务行加灰色「任务」tag 区分。
- CSV 类型列支持「任务」→ kind='task'，校验规则与弹窗一致。
- 旧数据（kind=''）完全不受影响；编辑弹窗可在三种类型间互转（分组有子项时禁转）。

## 非目标
- 不做三级树（1.1.1）、不做拖拽调日期、不做任务独立详情页（复用 msDrill）。

## 验收标准
1. 甘特顶部显示「项目名 + 总时长 N 天」总条，区间=实际内容跨度。
2. 新增任务（类型=任务）→ 甘特出现工期条 + 「任务」tag，完成状态计入项目进度。
3. 任务不填结束日期被拦截；CSV 任务行导入 kind='task'。
4. verify 全绿（C27 批次含：三选项双站点计数==2、项目总条渲染、任务进度联动、回归 C25/C26）。
