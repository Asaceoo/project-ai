# SupplyDevLocal 用户文档（使用手册）

> 适用版本：v1.0.51（构建时自动同步） ｜ 最后更新：2026-10-01 ｜ 平台：Windows 10/11 桌面应用（双击 exe 即用，无需安装）
> 本地私有化供应链管理系统：项目管理、供应商、订单、打样、成本核算、质量跟进，数据全部存在本机。

---

## 1. 快速上手

### 1.1 启动与登录
1. 双击 `SupplyDevLocal-vX.Y.Z.exe`（文件名里的版本号随发版自动递增），等待约 3-5 秒打开主窗口。
2. **首次使用**：输入用户名 + 密码，点「创建账号并进入」。账号仅存在本机，用于操作留痕（谁做的改动记在操作日志里）。
3. **再次启动**：输入密码登录。密码错误无法进入；忘记密码请看「6. 常见问题」。

### 1.2 界面布局
左侧导航共 8 个板块 + 项目详情页：

| 导航 | 功能 |
|---|---|
| 仪表盘 | 全局 KPI、待办提醒、甘特图、关键日期看板、风险提醒、近期到期节点、项目状态分布、最近动态 |
| 项目汇总 | 所有产品的列表、新增/编辑/删除，点击进入详情页 |
| 产品与打样 | 打样轮次跟进、倒计时、费用 |
| 成本核算 BOM | 产品 BOM 组成、报价对比、成本快照 |
| 供应商管理 | 供应商档案、评分评级、资质证书到期 |
| 订单跟进 | 订单进度步、交期、付款状态 |
| 质量跟进 | 客诉、到货抽检、8D 整改 |
| 团队成员 | 成员管理、操作日志（含归档） |
| 帮助中心 | 三分钟上手、逾期处理指南、核心规则、快捷键、FAQ（软件内随时可查） |

顶栏有**全局搜索框**（支持 12 类实体）；页面内常用操作在右上角「🔄 刷新」「🔍 自检」「🖨 报表」等工具按钮。

## 2. 核心业务流程

### 2.1 一个新产品的完整链路
```
新增项目 → 建里程碑（自动算进度）→ 找供应商打样 → 报价对比
→ 确认 BOM 成本 → 下订单 → 跟跟进质量 → 完工/归档
```

1. **新增项目**（项目汇总 → 新增）：填名称、品类、平台、负责人、目标售价、打样截止、目标交期。系统自动生成默认里程碑，**进度 = 里程碑完成比例**，手动改不了进度（防数据打架）。
2. **里程碑**：项目详情页添加/编辑/删除。拖动状态为「完成」后，仪表盘甘特图、关键日期看板、所有进度指标**立即联动**，无需手动刷新。
3. **打样**（产品与打样页）：记录轮次、费用、截止日。临近截止有倒计时，逾期标红。
4. **报价**（成本核算 BOM 页）：多家供应商比价，采纳某家后自动写入供应商价格分并更新成本快照。报价过有效期会红字提醒。
5. **BOM 成本**：BOM 行可挂物料或半成品（嵌套），工艺费与损耗率自动摊入成本。
6. **订单**：按进度步推进（下单→生产→运输→收货），全部收货后项目自动置「已完工」+ 进度 100%（终态不会被重算拉回）。
7. **质量**：客诉 / 到货抽检 / 8D 整改闭环。客诉与逾期事件**自动**计入供应商质量分、交期分。

### 2.2 供应商评分规则（重要，请勿纠结手动改分）

| 分项 | 谁在维护 | 说明 |
|---|---|---|
| 质量分 | **系统自动** | 由客诉事件计算；无事件时基线 95 分。编辑弹窗中此框只读 |
| 交期分 | **系统自动** | 由逾期事件计算；无事件时基线 90 分。编辑弹窗中此框只读 |
| 价格分 | **人工填写** | 你在编辑供应商时填写的分数会被保留，不被覆盖 |
| 综合评级 | 系统自动 | 按品类的质量/交期/价格权重（品类权重页可调）加权得出 |

> 想提分，走业务动作：减少客诉、避免订单逾期。直接改数据库没用——每次保存都会按公式重算。

## 3. 仪表盘怎么看

| 面板 | 内容与联动时机 |
|---|---|
| KPI 卡片 | 在研项目 / 本月到期 / 即将到期(≤3天) / 已逾期 / 在途货值 / 待处理客诉，任何数据变更即时刷新；「已逾期」各板块口径一致：终态（已完工/已归档）项目与已收货订单不计，订单按最近未收货批次交期算 |
| 待办提醒 | 逾期订单、临期打样、证书到期等聚合清单 |
| 甘特图 | 各项目里程碑时间条，点条直达详情 |
| 关键日期看板 | 未来 N 天的关键节点 |
| 风险提醒 | 逾期订单、超期客诉、证书过期等风险聚合 |
| 项目状态分布 | 按状态统计的分布图 |
| 最近动态 | 最近操作流水 |

| 逾期处理（v1.0.47 新增） | 集中列出全部逾期事项：类型/逾期对象/位置/应完成时间/逾期天数/怎么处理，点击行直达处理；已完工/已归档项目不计逾期 |

**实时性保障**：所有面板派生自同一数据源，改完即刷新；程序挂机跨天、电脑休眠唤醒、切走再切回，倒计时与逾期标记都会自动重算，不会看到昨天的旧数据。

## 4. 数据管理（导入 / 导出 / 备份）

### 4.1 CSV 导入导出
- **导出**：支持 15 个模块（物料库/项目/供应商/订单/工艺库/BOM/打样/报价/客诉/到货抽检/8D整改/里程碑/任务依赖/品类权重/资质证书）。项目详情页内导出只含当前项目的行。
- **导入**：CSV 按表头匹配，导入前有预览确认。JSON 全量备份导入支持「撤销」——导错可回滚最近 3 次导入会话。

### 4.2 JSON 全量备份
导出时可选**备份密码**（AES-GCM 加密）；密码遗忘不可恢复，请妥善保管。

### 4.3 自动备份（无需操作，但要了解）
- 启动时自动备份一次；运行中每 5 分钟巡检，**距上次成功备份满 24 小时且期间有数据变更**才会再备一份（不会反复写盘）。
- 备份位置：`C:\Users\<你>\.supplydev\backups\`，滚动保留最近 7 份，超出的自动清理。
- 启动约 15 秒后自动校验最新备份完整性，损坏/缺失会弹提示。
- **超过 7 天没有成功备份**会提醒。

### 4.4 数据自检（🔍 自检按钮）
怀疑数据不对（进度、评分、状态跟实际对不上）时，点任意页面的「🔍 自检」：系统全量重算一遍派生数据并自动修复漂移，弹窗告诉你修了几个字段。已完工/已归档的项目不会被改写。

## 5. 实用技巧

- **全局搜索**：顶栏输入即可搜项目/供应商/订单/客诉/物料/里程碑/报价/证书/整改/抽检/工艺/成员，点结果直达对应页面。
- **逾期悬浮说明**：任何板块的逾期标记，鼠标悬停即可看到「哪里逾期 + 应完成时间 + 建议处理方式」。
- **快捷键**：`Ctrl+K` 聚焦搜索、`Alt+1~9` 切换九大板块、`Ctrl+S` 立即落盘、`Esc` 关弹窗。
- **编辑模式**：各板块行内均有「编辑」按钮，弹窗修改后保存即联动刷新。
- **删除**：物料/BOM 等删除会**级联清理**关联数据，不会留孤儿行。
- **操作日志**：团队成员页可查最近操作；超过 300 条自动转入「查看归档」，可一键导出全量 CSV。
- **打印报表**：详情页「🖨 报表」生成可打印页面，浏览器另存为 PDF。

## 5.5 效率技巧（v1.0.49 新增）

- **点数字直达明细**：仪表盘的 KPI 卡（已逾期、即将到期、在研项目等）、近 6 月趋势柱、状态分布图例都能点击，会自动跳到对应页面并**带上筛选条件**，不用再手动筛一遍。
- **项目健康度**：项目汇总的卡片和列表都有彩色徽章——红=逾期、橙=7 天内到期、绿=健康、灰=未排期/已完成；列表默认把最危险的项目排在最前面。
- **列表排序**：点击列头（项目名称/状态/品类/目标交期等）切换排序，再点一次反向。
- **批量操作**：勾选项目（卡片或列表均可，支持全选，跨页保留），顶部出现批量工具条：一键改状态、导出选中 CSV、批量删除（有订单的项目自动跳过并提示）。

## 5.6 项目逾期怎么算（v1.0.50 更新，重要口径）

- **已完工/已归档**：显示「✓ 已完成」，永不显示逾期。
- **「交付」里程碑已完成**：显示绿色「✓ 已交付」，不再计逾期——在项目详情里把交付里程碑改为已完成，项目汇总的红标会立即消失（数据自动同步）；需要正式结转时再在编辑项目里把状态改为「已完工」。
- **未下单阶段（立项中/打样中）**：按**打样截止日**判断临期/逾期——此阶段目标交期只是计划值，不作为考核依据。
- **已下单/生产中**：按**目标交期**判断——下单后交付承诺生效。
- KPI 卡（已逾期/即将到期/本月到期）、筛选器、列表倒计时、卡片徽章、甘特图全部使用同一口径。

## 5.7 OTIF 与三档抽检（v1.0.51 新增）

- **OTIF 达成率**（订单管理页 KPI）：衡量供应商「足额准时」交付的行业标杆指标（目标 95-98%）。口径=分批交付且已足额收货的订单里，**每批实收日期都没晚于承诺日期**的占比。确认收货时自动记录实收日期；无分批的订单没有收货记录，不计入。订单行内也会标出 `OTIF ✓`（绿）或 `OTIF ✕`（橙）；供应商列表的交期分下方可见每家供应商的 OTIF 汇总。
- **三档 AQL 抽检**（到货抽检）：录入时分别填写**致命 / 主要 / 次要**不良数，系统按 GB/T 2828.1（水平Ⅱ）自动算出抽检数并判定：致命 Ac=0（出现即退货）、主要按 AQL 1.0、次要按 AQL 4.0。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 忘记登录密码 | 删除 `C:\Users\<你>\AppData\Local\supplydev\`（exe 数据目录）下的 localStorage 后重启可重设账号；**业务数据不受影响**，操作前建议先备份 |
| 打开白屏/很慢 | 首次启动 WebView2 初始化需数秒；仍异常则重启 exe |
| 数据疑似错乱 | 点「🔍 自检」自动修复；还不对就用 JSON 导出+导入做一次归位 |
| 备份提示 corrupt | 最新备份文件损坏，旧备份还在 backups 目录，可手动取回 |
| 想迁移到另一台电脑 | 拷贝 exe + JSON 全量导出文件，在新机器导入即可 |
| 供应商质量分改不了 | 这是设计如此（公式自动分），见 2.2 |
| 已完成的项目还显示逾期 | 先看 5.6 口径：未下单阶段按打样截止日算；把详情页「交付」里程碑改为已完成会立即转绿「✓ 已交付」。若仍异常，点「🔍 自检」 |
